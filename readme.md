# La Física-Aventura: Videojuego Educativo de Cinemática (Saber 11)

Un videojuego web interactivo desarrollado para estudiantes de la I.E. Josefa Campos en Bello, Antioquia, diseñado para la preparación en pruebas ICFES Saber 11° en el área de Ciencias Naturales (Física - Cinemática).

## Estructura del Proyecto

- `index.html` - Redirección inicial.
- `portada.html` - Portada, registro de jugador y mapa de mundos.
- `mundo1-mru.html` - Mundo 1: Movimiento Rectilineo Uniforme (MRU).
- `mundo2-mua.html` - Mundo 2: Movimiento Uniformemente Acelerado (MUA).
- `mundo3-caida-libre.html` - Mundo 3: Caída Libre.
- `mundo4-parabolico.html` - Mundo 4: Movimiento Parabólico.
- `mundo5-circular.html` - Mundo 5: Movimiento Circular Uniforme (MCU).
- `final.html` - Resumen pedagógico y epílogo.
- `guion-narrativo.md` - Guión narrativo y diálogos pedagógicos.

## Características Principales

1. **Simulaciones Físicas Interactivas con HTML5 Canvas**: Canvas interactivo con controles de velocidad, aceleración, tiempo, ángulos y gráficos en tiempo real.
2. **Gráficas Cinemáticas en Tiempo Real**: Muestra $x(t)$, $v(t)$, $a(t)$ dinámicamente.
3. **Preguntas Tipo ICFES Saber 11°**: Retroalimentación detallada y explicaciones conceptuales en cada mundo.
4. **Narrativa Integrada**: Historia contextualizada en el municipio de Bello, Antioquia.
